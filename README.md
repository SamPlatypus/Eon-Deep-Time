# Eon

A deep-time atlas of Earth. Scrub from the Cambrian (−540 Ma) to a future Pangea Proxima (+250 Ma) and watch plates, sea level, mountains, and biomes change.

The reconstruction runs on the device: rigid-plate rotations, a zonal energy-balance climate model, and a Whittaker biome map with rain shadows. Drag the globe to spin it. The three dots at the bottom raise and drop the menu. Install from that menu to open Eon from a home-screen icon.

```bash
npm install
npm run dev
```

The compiled site is published from `main` by GitHub Actions to [samplatypus.github.io/Eon-Deep-Time](https://samplatypus.github.io/Eon-Deep-Time/).
